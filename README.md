# Twimba

A simple Twitter/X-inspired social media web application built with JavaScript and Vite.

## Features

* View posts and tweets
* Like posts
* Retweet posts
* Reply to posts
* Responsive and simple UI
* Dynamic content rendering with JavaScript

## Tech Stack

* HTML
* CSS
* JavaScript
* Vite

## Getting Started

Clone the repository:

```bash
git clone https://github.com/as3prit3/Twimba.git
cd Twimba
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Then open the local URL provided by Vite in your browser.
